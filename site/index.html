Current app surface

MAGI is not a landing-page mockup. The desktop app currently ships a replay database, trend dashboard, sessions view, library filters, character pages, practice plans, Oracle chat, and game theater.

Replay database

Parallel import, SHA-256 dedupe, local SQLite storage, watcher support, and filters for opponent, matchup, stage, and result.

Performance tracking

Dashboard cards and trend charts cover neutral, L-canceling, conversions, damage per opening, openings per kill, and death percent.

AI coaching

Streaming game coaching, session reports, character-scope analysis, generated drills, and Oracle chat grounded in local game context.

Provider control

Pollinations no-key fallback, OpenAI, OpenRouter, Anthropic, Gemini, and local OpenAI-compatible endpoints through Ollama or LM Studio.

Replay review

Slippi Dolphin launch, timestamp-to-frame seeking, stock timeline review, and Windows-first embedded replay with external fallback.

Local-first defaults

No account, no MAGI server, no bundled keys. Config and replay-derived data stay under the local `~/.magi-melee` directory.

New UI screenshots

These captures come from the current Electron app shell after the UI overhaul. Settings is omitted to avoid exposing local paths or keys.

Workflow

The app is built around repeated review: import, inspect, ask, drill, and return to the next session with a narrower focus.

Import

Point MAGI at a Slippi folder or import replay files manually.

Measure

Review stats, matchups, sessions, and recent-form trends.

Ask

Use game coaching, Oracle chat, or session reports for specific feedback.

Review

Open timestamps in Dolphin or the embedded replay surface where supported.

Practice

Generate drills from weakness patterns and track completion.

Build from source

Electron, Vite, React, SQLite, and Slippi parsing.
